# 지뢰찾기 (Minesweeper) - Python (Tkinter) 버전

이 저장소는 Python과 Tkinter를 이용한 윈도우용 데스크탑 지뢰찾기 게임입니다.

## 주요 기능
- **마우스 좌클릭**: 셀 열기
- **마우스 우클릭**: 깃발 표시/해제
- **게임 재시작**: '재시작' 버튼 클릭
- **난이도 변경**: 초급/중급/고급 버튼 제공
- **승리/패배 알림**: 상황에 따라 메시지 표시

## 사용 방법

1. Python 3.x가 설치되어 있어야 합니다.
2. 필요한 GUI 라이브러리 설치:
   - Tkinter는 대부분 Python에 기본 포함되어 있습니다.
3. 터미널에서 아래 명령으로 실행하세요.

```bash
python minesweeper.py
```

## 파일 설명

- `minesweeper.py` : 메인 게임 파일입니다.
- `README.md` : 이 설명서 파일입니다.

## 난이도

- **초급**: 9x9, 지뢰 10개
- **중급**: 16x16, 지뢰 40개
- **고급**: 16x30, 지뢰 99개
